# 성적 CSV 검증 프로그램

## ① 무엇을 하나요 (What)

성적 CSV 파일을 읽어 유효한 성적은 목록으로 반환하고, 잘못된 행은 건너뛴 이유와 함께 기록합니다.

## ② 왜 만들었나요 (Why)

성적 CSV에는 빈 값, 숫자가 아닌 점수, 0~100 범위를 벗어난 점수, 열 개수가 다른 행이 포함될 수 있습니다. 이런 행 하나 때문에 전체 처리가 중단되지 않도록 유효한 성적과 건너뛴 행을 구분하고, 문제가 있는 행과 그 이유를 확인할 수 있게 만들었습니다. 같은 이름도 동명이인일 수 있으므로 모두 보존합니다.

## ③ 어떻게 쓰나요 (How)

Python이 설치된 환경에서 `week11_files` 폴더로 이동한 뒤 실행합니다.

```bash
# 테스트 도구 설치
python -m pip install pytest

# scores.csv 읽기
python load_scores.py scores.csv
```

## ④ 어떻게 테스트하나요

```bash
python -m pytest -q
```

## ⑤ 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `load_scores.py` | 성적 CSV를 읽고 유효한 점수와 건너뛴 행을 반환합니다. |
| `test_load_scores.py` | 성적 CSV 처리의 정상·예외·경계 조건을 검사합니다. |
| `test_a.py` | 코드 제공 프롬프트로 만든 테스트입니다. |
| `test_ai_B.py` | 명세 제공 프롬프트로 만든 테스트입니다. |
| `bug3_logic.py` | 최고점·합격자 수 계산의 논리 오류를 살펴보는 예제입니다. |
| `scores.csv` | 정상 및 잘못된 값이 함께 들어 있는 예제 성적 파일입니다. |
| `empty.csv` | 헤더만 있는 빈 성적 파일입니다. |
| `weird.csv` | 다양한 입력 오류를 확인하기 위한 예제 파일입니다. |
| `prompts.txt` | 실습에서 사용한 프롬프트와 테스트 비교 안내입니다. |
